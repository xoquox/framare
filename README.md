# Framare

SailfishOS-Projekt zum Senden von Bildern an Frameo-kompatible Bilderrahmen.
Technischer Paketname: `harbour-framare`.

**Stand: Entwicklungsumgebung eingerichtet und mit SDK-Test-RPMs für aarch64
und armv7hl geprüft. Es gibt noch keine Framare-App und kein Framare-RPM.**

Das Repository enthält Nix-Konfigurationen, SDK-Starter, Buildprüfungen und
die technischen Befunde zum festgelegten
[unframeo](https://github.com/borje/unframeo)-Quellstand.

Framare ist ein unabhängiges Projekt ohne behauptete Verbindung zu Frameo,
Jolla oder Trifork. unframeo steht unter GPL-3.0-or-later; Hinweise zu Herkunft
und Lizenzprüfung stehen in [docs/unframeo.md](docs/unframeo.md).

Einrichtung, vorhandene Prüfergebnisse und noch ausstehende Tests stehen in
[docs/environment.md](docs/environment.md). Allgemeine Entwicklerhinweise
stehen in [AGENTS.md](AGENTS.md).
